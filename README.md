# SIH26011 — 3D ULPIN Pro Prototype

Standalone, no-API, no-CDN prototype.

Core flow:
Dashboard → 3D Property Map → Floor → Unit → 3D coordinates → Proposed identifier → Validation → Registry → Analytics.

Run by opening `index.html` in Chrome/Edge.

Important: all geometry, coordinates, identifiers and validation records are demonstration data. They are not official ULPINs, cadastral coordinates, legal titles or government-certified records.
